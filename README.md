# UnSmoke

A premium quit-smoking & NRT companion for Android.

![Kotlin](https://img.shields.io/badge/Kotlin-2.4.10-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![Platform](https://img.shields.io/badge/Platform-Android-green.svg)
![Architecture](https://img.shields.io/badge/Architecture-Clean-orange.svg)

## Features
- Quit Tracking & Calculations
- Craving Management (Breathing Orb)
- NRT (Nicotine Replacement Therapy) Usage Logging
- Journaling & Mood Tracking
- Daily Check-ins
- Achievements & Milestones

## Tech Stack
| Component | Technology |
| --- | --- |
| UI | Jetpack Compose |
| Architecture | MVVM + Clean Architecture |
| DI | Hilt |
| Database | Room 3.0 |
| Async | Coroutines + Flow |
